# 施設基準等に関する掲示事項

このリポジトリは、社会医療法人博寿会 山本病院における施設基準、加算、保険外負担等に関する掲示事項を、GitHub Pagesで公開するための静的Webページです。

病院ホームページ本体とは別に公開し、病院ホームページのお知らせ欄からこのGitHub PagesのURLへリンクする運用を想定しています。

## ファイル構成

```text
/
  index.html
  style.css
  script.js
  pdf-list.json
  /pdf/
    README.md
  /thumb/
    README.md
  README.md
```

## GitHub Pagesで公開する方法

1. このファイル一式をGitHubリポジトリに配置します。
2. GitHubのリポジトリ画面で「Settings」を開きます。
3. 左側メニューの「Pages」を開きます。
4. 「Build and deployment」で「Deploy from a branch」を選びます。
5. 公開するブランチを選び、フォルダは「/ (root)」を選びます。
6. 保存後、表示されたGitHub PagesのURLを開いて確認します。
7. そのURLを病院ホームページのお知らせ欄に掲載します。

独自ドメインは使わず、通常のGitHub Pages URLで公開する前提です。

## PDFを差し替える方法

1. 新しいPDFを準備します。
2. `pdf/` フォルダ内の同じファイル名のPDFを上書きします。
3. 必要に応じて、PDFと同じ名前のサムネイル画像を `thumb/` フォルダ内で上書きします。
4. GitHubへ反映し、GitHub Pages上でPDFリンクが開けることを確認します。

PDF本文はWebページ内に直接書かず、PDFファイルで管理します。

サムネイル画像がある場合はカード上部に表示されます。サムネイル画像がない場合は、代わりにPDFアイコンが表示されます。

## 新しいPDF項目を追加する方法

1. `pdf/` フォルダに新しいPDFを追加します。
2. `pdf-list.json` にPDFファイル名を1行追加します。
3. サムネイルを表示したい場合は、`thumb/` フォルダに同じ名前の画像を追加します。
4. ページを開き、一覧に追加した項目が表示されることを確認します。

## pdf-list.json の編集方法

`pdf-list.json` はPDF一覧を管理するファイルです。通常はPDFファイル名だけを並べます。

GitHub Pagesは静的サイトのため、`pdf/` フォルダ内のPDFを自動で一覧取得することはできません。そのため、新しいPDFを追加した場合は `pdf-list.json` にファイル名を1行追加します。

```json
[
  "01.厚生労働大臣の定める掲示事項.pdf",
  "02.施設基準届出一覧.pdf"
]
```

ページ上の項目名には、PDFファイル名から先頭の番号と `.pdf` を除いた文字列が使われます。

例えば、`01.厚生労働大臣の定める掲示事項.pdf` は、ページ上では `厚生労働大臣の定める掲示事項` と表示されます。

JSONでは、最後の項目の後ろに余分なカンマを付けないよう注意してください。

説明文や更新日を表示したい場合だけ、次のように詳しい形式も使えます。

```json
[
  {
    "title": "医療DX推進体制整備加算に関する掲示",
    "description": "医療DX推進体制整備加算に関する当院の掲示事項です。",
    "file": "01.医療DX推進体制整備加算に関する掲示.pdf",
    "thumbnail": "01.医療DX推進体制整備加算に関する掲示.jpg",
    "updated": "2026-06-12"
  }
]
```

## ファイル名の運用ルール

公開用PDFのファイル名は固定してください。更新時は同じファイル名で上書きします。

PDFファイル名は `01.○○.pdf`、`02.○○.pdf` のように、先頭に表示順の番号を付けます。
ページ上では先頭の番号と `.pdf` を除いた文字列が項目名になります。

ファイル名の例です。

- `01.厚生労働大臣の定める掲示事項.pdf`
- `02.施設基準届出一覧.pdf`
- `03.保険外負担に関する事項.pdf`

日付入りのファイル名は使わないでください。

悪い例です。

- `医療DX推進体制整備加算に関する掲示_20260612.pdf`

ファイル名に日付を入れると、更新のたびに `pdf-list.json` のリンク修正が必要になります。GitHub Pages上では常に固定ファイル名で公開し、履歴管理用PDFは院内の別フォルダで管理してください。

## サムネイル画像の運用ルール

サムネイル画像は `thumb/` フォルダに置きます。PDFと同じ名前で、拡張子だけ `.jpg` にしてください。

例です。

```text
pdf/01.厚生労働大臣の定める掲示事項.pdf
thumb/01.厚生労働大臣の定める掲示事項.jpg
```

`.jpg` が見つからない場合は `.png` も探します。どちらも見つからない場合は、PDFアイコンが表示されます。

## ローカルでの動作確認方法

このページは `pdf-list.json` をJavaScriptで読み込むため、ブラウザで `index.html` を直接開くと環境によって一覧が表示されない場合があります。

ローカル確認では、このフォルダで簡易サーバーを起動してください。

```powershell
py -m http.server 8000
```

起動後、ブラウザで次のURLを開きます。

```text
http://localhost:8000/
```

確認が終わったら、ターミナルで `Ctrl + C` を押して停止します。

## 「PDF一覧を読み込めませんでした」と表示される場合

`index.html` をダブルクリックして直接開いた場合、ブラウザの制限により `pdf-list.json` を読み込めず、このメッセージが表示されることがあります。

確認するときは、上記のローカルサーバーを起動して `http://localhost:8000/` で開いてください。GitHub Pagesで公開した後は、GitHub PagesのURLから開くことでPDF一覧が表示されます。

## 病院ホームページのお知らせ欄に掲載する文例

```text
施設基準等に関する掲示事項を掲載しました

当院における施設基準、加算、保険外負担等に関する掲示事項を以下のページに掲載しています。

施設基準等に関する掲示事項はこちら
```

「施設基準等に関する掲示事項はこちら」の部分に、GitHub PagesのURLをリンクとして設定してください。

## 公開前チェックリスト

- GitHub Pagesのページが開ける
- PDFリンクが開ける
- スマートフォンで見やすい
- 病院名が正しい
- 電話番号や住所が表示されていない
- 不要な個人情報がPDFに含まれていない
- PDFファイル名が固定運用になっている
- PDFファイル名が `01.○○.pdf` の形式になっている
- `pdf-list.json` に掲載するPDFファイル名が入っている
- サムネイルを使う場合は、`thumb/` フォルダに同名画像が入っている
- 病院ホームページのお知らせ欄からリンクできる

## 更新時チェックリスト

- PDFを同じファイル名で上書きした
- サムネイルを使う場合は、同じ名前の画像を `thumb/` フォルダで上書きした
- 新しい項目を追加した場合は `pdf-list.json` にPDFファイル名を追記した
- GitHub PagesでPDFリンクが開ける
- 表示内容に不要な個人情報や内部資料が含まれていない
- 病院ホームページのお知らせ欄からのリンク先が変わっていない

## 担当者が退職・異動した場合の注意点

- GitHubリポジトリの管理者を複数名にしておくことを推奨します。
- GitHubアカウント、リポジトリ、GitHub Pages URLの管理情報を院内で共有してください。
- PDFの原本や履歴管理用PDFは、GitHub上ではなく院内の所定フォルダで管理してください。
- 公開用PDFに患者個人情報や内部資料が含まれないよう、更新時に必ず確認してください。
- 病院ホームページのお知らせ欄からGitHub Pagesへリンクする運用であることを、引き継ぎ資料に記載してください。
