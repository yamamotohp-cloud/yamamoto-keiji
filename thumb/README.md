# サムネイル画像フォルダの運用ルール

このフォルダには、PDF一覧に表示するサムネイル画像を置きます。

## 基本ルール

- サムネイル画像は公開用PDFの1ページ目を画像化したものにする
- 画像ファイル名はPDFと同じ名前にする
- 拡張子は原則として `.jpg` にする
- `.jpg` が使えない場合は `.png` でもよい
- サムネイルがないPDFは、ページ上ではPDFアイコンで表示される
- 患者個人情報や内部資料が画像に含まれないよう注意する

## ファイル名の例

```text
pdf/01.厚生労働大臣の定める掲示事項.pdf
thumb/01.厚生労働大臣の定める掲示事項.jpg
```

PDFを差し替えた場合は、必要に応じてサムネイル画像も同じファイル名で上書きしてください。
