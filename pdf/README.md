# PDF保管フォルダの運用ルール

このフォルダには、GitHub Pagesで公開するPDFのみを置きます。

## 基本ルール

- このフォルダには公開用PDFのみを置く
- PDFファイル名は固定する
- PDFファイル名は `01.○○.pdf`、`02.○○.pdf` の形式にする
- PDFを更新するときは同じファイル名で上書きする
- 古いPDFの履歴管理はGitHub上ではなく、院内の別フォルダで管理する
- 患者個人情報や内部資料を誤って置かないよう注意する

## ファイル名の例

```text
01.厚生労働大臣の定める掲示事項.pdf
02.施設基準届出一覧.pdf
03.保険外負担に関する事項.pdf
```

日付入りのファイル名は使わず、GitHub Pages上では固定ファイル名で公開してください。
